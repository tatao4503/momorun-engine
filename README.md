# 모모런 엔진 (MomoRun Engine)

**최애 캐릭터와 함께 걷는 만보기 엔진.**
캐릭터는 앱에 들어있지 않습니다. 이름·색·사진을 직접 채워 넣으면, 그 캐릭터가 오늘 걸음을 정리해 줍니다.

> A pedometer engine you fill with your own favorite character.
> No character artwork is bundled — you bring your own, and it stays on your device.

---

## 무엇인가

만보기는 많지만, **"내 최애가 옆에서 같이 걸어주는"** 만보기는 없었습니다.
그런 앱을 만들려면 캐릭터를 앱에 넣어야 하는데, 남의 캐릭터는 넣을 수 없습니다.

이 엔진은 그 문제를 뒤집어서 풉니다 — **앱은 빈 액자로 배포되고, 캐릭터는 사용자가 채웁니다.**

- 캐릭터 = 데이터 (대사·색·배경·랭크·반응)
- 엔진 = 캐릭터를 모름 (`window.MomoCharacter`를 읽을 뿐)
- 사용자가 넣은 이름·색·사진은 **기기에만** 저장되고 어디로도 전송되지 않음

## 들어있는 것

| 모드 | 설명 |
|---|---|
| **라이트** | 오늘 걸음·목표·최근 7일. 가장 가벼운 화면 |
| **일상** | HealthKit 연동, 주간 기록 카드, 알림 (iOS 앱 빌드 시) |

기본 제공 팩 2종 (둘 다 오리지널, IP 없음):
- **루미** — 엔진 시연용 샘플 캐릭터
- **빈 동행팩** — 특정 캐릭터를 가정하지 않는 중립 대사팩. *내 최애를 넣는 자리*

## 바로 써보기

```bash
python3 -m http.server 8080
# http://localhost:8080/modes.html
```

정적 파일만 있으면 됩니다. 빌드 과정도, 서버도, 계정도 필요 없습니다.

## 내 최애 넣기

1. 버전 선택 화면 → **내 최애 넣기** 팩 선택
2. 우측 상단 **캐릭터** → 이름·포인트 색·사진 입력 → 저장
3. 라이트나 일상 버전으로 시작

사진은 브라우저에서 압축돼 로컬에 저장됩니다. 서버로 올라가지 않습니다.

## 캐릭터 팩 만들기

두 가지 방법이 있습니다.

**1. 설정에서 (비개발자용)**
이름·색·사진만 바꾸는 방식. 팩 파일로 내보내고 가져올 수 있습니다.
팩은 `visual-only` — 실행 코드나 외부 주소를 담지 않으며, 알 수 없는 항목이 있으면 통째로 거부합니다.

**2. 팩 파일 작성 (개발자용)**
`original/companion/character.js`를 복사해 대사·랭크·테마까지 직접 정의할 수 있습니다.

```js
window.MomoCharacterCatalog.myPack = {
  id: 'myPack',
  name: '이름',
  availability: ['lite', 'life'],
  theme: { backgrounds: {...}, surfaces: {...} },   // 화면별 CSS 변수
  ranks: [...],                                      // 누적 걸음 단계
  lines: { greetingByTime, start, stop, milestones, life, lite },
  notifications: {...},
};
```

엔진 코드는 건드리지 않습니다. 팩 파일 하나 + 이미지 몇 장이면 새 캐릭터가 됩니다.

## 설계 원칙

- **엔진은 캐릭터를 모른다** — 하드코딩된 캐릭터 이름·대사가 없습니다
- **네트워크 없음** — 걸음 기록은 로컬 저장소에만. 계정도, 서버도, 추적도 없습니다
- **팩에 코드를 담지 않는다** — 가져온 팩이 코드를 실행할 수 없습니다
- **저장 실패에 관대하다** — 사생활 모드처럼 저장이 막히면 메모리로 전환하고 안내합니다
